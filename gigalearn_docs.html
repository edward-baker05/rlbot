GigaLearn & RLGymCPP Documentation

Ultra-fast, native C++ reinforcement learning ecosystem for Rocket League bots powered by RocketSim, RLGymCPP, and LibTorch.

💡 Architecture Design

GigaLearn is divided into two decoupled layers: RLGymCPP handles high-speed environment stepping, observation calculation, action masking, and reward computations. GigaLearnCPP manages multi-arena PPO training, policy inference, neural network optimization, automatic entropy control, and self-play versioning.

Component Namespace / Header Primary Purpose
Rewards RLGC::Reward, CommonRewards.h Per-player reward computations evaluated at every decision tick.
Terminal Conditions RLGC::TerminalCondition Decides when an episode finishes (Goal scored, ball timeout, step limit).
State Setters RLGC::StateSetter Resets arena ball and car positions (Kickoff, random spawns, aerial setups).
Observation Builders RLGC::ObsBuilder Translates raw game physics into normalized tensors for the policy & critic.
Action Parsers RLGC::ActionParser Translates discrete action indices into throttle/steer/pitch/yaw/jump/boost controls.
EnvSet Engine RLGC::EnvSet Runs hundreds of multi-threaded RocketSim arenas simultaneously.
PPO Learner GGL::Learner, PPOLearnerConfig.h Handles GAE, PPO clipping, adaptive entropy control, and PyTorch gradient steps.

🚀 Quickstart: Building an Environment

Environments are instantiated via factory functions passed to RLGC::EnvSet or GGL::Learner.

C++ • Env.cpp 
#include <RLGymCPP/EnvSet/EnvSet.h>
#include <RLGymCPP/Rewards/CommonRewards.h>
#include <RLGymCPP/TerminalConditions/GoalScoreCondition.h>
#include <RLGymCPP/TerminalConditions/NoTouchCondition.h>
#include <RLGymCPP/StateSetters/RandomState.h>
#include <RLGymCPP/ObsBuilders/DefaultObs.h>
#include <RLGymCPP/ActionParsers/DefaultAction.h>

using namespace RLGC;

EnvCreateResult CreateEnv(int index) {
    Arena* arena = Arena::Create(GameMode::SOCCAR);
    arena->AddCar(Team::BLUE);
    arena->AddCar(Team::ORANGE);

    EnvCreateResult result = {};
    result.arena = arena;
    result.actionParser = new DefaultAction();
    result.obsBuilder = new DefaultObs();
    result.stateSetter = new RandomState(true, true, false);
    
    // Define rewards with scale weights
    result.rewards = {
        { new GoalReward(), 1.0f },
        { new TouchAccelReward(), 0.15f },
        { new VelocityBallToGoalReward(), 0.05f }
    };

    // Terminal episode end conditions
    result.terminalConditions = {
        new GoalScoreCondition(),
        new NoTouchCondition(12.0f) // Truncate after 12s with no touch
    };

    return result;
}

🎁 Reward Functions Catalog

Browse all built-in reward classes provided by GigaLearn in RLGC::.

Ball & Goal Rewards

GoalReward Sparse • Zero-Sum
Rewards a goal scored by any player on the team. Automatically zero-sum against the defending team.
scored ? +1.0 : concedeScale (-1.0)
float concedeScale: Multiplier for team conceding goal (default: -1.0)
PlayerGoalReward Event • Individual
Given only to the single player who touched the ball last on the scoring team.
player.eventState.goal ? +1.0 : 0.0
VelocityBallToGoalReward Dense • Directional
Dot product between normalized ball velocity and direction vector from ball to opponent's back net center.
(v_ball / 6000) • dir(ball → goal) ∈ [-1, 1]
bool ownGoal: Targets own goal if true (default: false)
ShotReward Event
Triggered on the tick a player hits the ball on target towards the opponent's goal net.
player.eventState.shot ? +1.0 : 0.0
ShotPassReward Event • Teamwork
Rewards a pass from a teammate that directly leads to a registered shot on goal.
player.eventState.shotPass ? +1.0 : 0.0
SaveReward Event • Defense
Awarded when a player makes contact with a goal-bound ball in their defensive zone, preventing a goal.
player.eventState.save ? +1.0 : 0.0

Touch & Acceleration Rewards

TouchBallReward Touch
Returns 1.0 on any step where the player's hitbox touched the ball at least once during physics substeps.
player.ballTouchedStep ? 1.0 : 0.0
TouchAccelReward Necto Classic • Touch
Rewards accelerating the ball towards 110 km/h upon contact. Caps at total reward 1.0 for speeding ball to max speed.
min(1, v_curr / 110kph) - min(1, v_prev / 110kph)
StrongTouchReward Impulse
Rewards the magnitude of the velocity vector change imparted onto the ball during touch. Filters out weak taps.
|v_ball(t) - v_ball(t-1)| / maxRewardedVel
float minSpeedKPH: Threshold to receive reward (default: 20)
float maxSpeedKPH: Cap for maximum reward 1.0 (default: 130)
VelocityPlayerToBallReward Dense • Approach
Dot product between car velocity vector and the normalized direction vector towards the ball.
(v_car / 2300) • dir(car → ball) ∈ [-1, 1]
FaceBallReward Orientation
Measures car nose alignment with the ball direction using car orientation rotation matrix forward vector.
rotMat.forward • dir(car → ball) ∈ [-1, 1]

Movement, Mechanics & Boost Rewards

SpeedReward Kinematic
Normalized scalar speed of the car relative to max driving speed (2300 uu/s).
|player.vel| / 2300.0 ∈ [0, 1]
VelocityReward Velocity
Velocity normalized by max car speed. Can be set to negative to penalize unnecessary movement.
(|player.vel| / 2300.0) * (isNegative ? -1 : 1)
bool isNegative: Inverts reward to penalty if true (default: false)
AirReward Mechanics
Returns 1.0 for each step the car is not in contact with the ground pitch (`!player.isOnGround`).
!player.isOnGround ? 1.0 : 0.0
WavedashReward Advanced Mechanic
Rewards the exact tick when car touches ground while in a dodge/flip state, executing a wavedash.
(isOnGround && prev->isFlipping && !prev->isOnGround) ? 1 : 0
PickupBoostReward Resource
Square root delta of boost gained from collecting small pads or big full pads. Returns 0 on boost consumption.
sqrt(boost / 100) - sqrt(prev_boost / 100)
SaveBoostReward Resource Conservation
Encourages holding boost reserves by granting reward proportional to available boost raised to an exponent.
clamp((boost / 100) ^ exponent, 0, 1)
float exponent: Curve curvature power (default: 0.5f)

Combat & Game Events

DemoReward Demolition
Reward awarded when supersonic car demolishes an opponent vehicle.
player.eventState.demo ? +1.0 : 0.0
DemoedPenalty Penalty
Penalty given to a player on the tick they are demolished.
player.eventState.demoed ? -1.0 : 0.0
BumpReward Physical Contact
Reward for colliding with an opponent car.
player.eventState.bump ? +1.0 : 0.0
BumpedPenalty Penalty
Penalty given when rammed or bumped by an opponent.
player.eventState.bumped ? -1.0 : 0.0

Reward Wrappers & Utility Classes

ZeroSumReward Zero-Sum & Team Spirit
Wraps any child reward to make it competitive (punishing opponent gains) and distributes rewards among teammates.
R = R_self*(1-spirit) + avg(R_team)*spirit - avg(R_opp)*scale
Reward* child: The inner reward function to wrap
float teamSpirit: Fraction [0.0 - 1.0] shared with teammates
float opponentScale: Multiplier on opponent punishment (default: 1.0)
PlayerReward<T> Per-Player Instance
Template container that automatically instantiates and resets an independent stateful reward instance per player index.
instances[player.index]->GetReward(...)

🛠️ Creating a Custom C++ Reward

Inherit from RLGC::Reward and override GetReward(). You can access all properties of Player and GameState.

C++ • CustomReward.h 
#pragma once
#include <RLGymCPP/Rewards/Reward.h>
#include <RLGymCPP/Math.h>

class BallApproachFacingReward : public RLGC::Reward {
public:
    // Optional reset hook called at the start of each episode
    virtual void Reset(const RLGC::GameState& initialState) override {}

    // Main reward calculation hook evaluated every step for each player
    virtual float GetReward(const RLGC::Player& player, const RLGC::GameState& state, bool isFinal) override {
        RLGC::Vec dirToBall = (state.ball.pos - player.pos).Normalized();

        // 1. How well is car facing the ball? (1.0 = directly facing, -1.0 = opposite)
        float facing = player.rotMat.forward.Dot(dirToBall);

        // 2. How fast is car moving towards the ball?
        float approachSpeed = player.vel.Dot(dirToBall) / RLGC::CommonValues::CAR_MAX_SPEED;

        // Only reward approach speed if facing forward
        if (facing > 0.2f && approachSpeed > 0.0f) {
            return facing * approachSpeed;
        }
        return 0.0f;
    }
};

⏱️ Terminal Conditions

Terminal conditions dictate when an episode ends. A condition can be an organic end (IsTruncation() = false, e.g. goal scored) or a timeout (IsTruncation() = true, so the value bootstrap is preserved).

Class Header Truncation? Description
GoalScoreCondition TerminalConditions/GoalScoreCondition.h False (Terminal) Returns true when state.goalScored is true. Triggers goal reset.
NoTouchCondition(maxTime) TerminalConditions/NoTouchCondition.h True (Truncated) Resets arena if elapsed time since the last ball touch exceeds maxTime seconds (e.g. 12s).
TimeoutCondition(maxTime) TerminalConditions/TimeoutCondition.h True (Truncated) Resets arena when total episode elapsed time exceeds maxTime seconds.

🎲 State Setters (Spawners)

State setters control the initial placement and velocities of the ball and cars upon reset.

KickoffState Standard
Resets arena to canonical Rocket League kickoff spawn locations at center pitch with zero initial velocity.
FuzzedKickoffState Anti-Determinism
Standard kickoff positions with slight floating point position fuzzing (±0.1 units). Prevents deterministic policy replay.
RandomState Exploration
Places ball and cars randomly across the entire pitch.
bool randBallSpeed: Give ball random velocity vector
bool randCarSpeed: Give cars random starting velocities
bool carsOnGround: Restrict cars to spawn on floor
CombinedState Weighted Mixture
Picks randomly between multiple state setters according to specified weights.
CombinedState({{ new RandomState(...), 0.7f }, { new KickoffState(), 0.3f }})

👁️ Observation Builders

Translates GameState and Player into a 1D tensor representation for the policy network.

Class Features Included Normalization Scales
DefaultObs Ball pos, vel, angVel.
Self & teammate & opponent cars (pos, rotMat, vel, angVel, boost, onGround, hasFlip).
34 boost pad status bits and timers. 		Pos: [1/4096, 1/5120, 1/2044]
Vel: 1/2300, AngVel: 1/5.5
AdvancedObs GigaLearn optimized relative observation representation.
Computes relative vectors to ball, goal, and nearest opponent. 		Pos: 1/5000
Vel: 1/2300, AngVel: 1/3.0
DefaultObsPadded Padded representation supporting variable team sizes (e.g. training 1v1, 2v2, 3v3 simultaneously with the same network size). Matches DefaultObs with zero-padding for absent players.

🎮 Action Parsers & Action Masking

Translates discrete integer action IDs into continuous controller inputs: { throttle, steer, pitch, yaw, roll, jump, boost, handbrake }.

DefaultAction (90 Discrete Actions + Masking)
Combines driving combinations on ground and flight pitch/yaw/roll/jump/boost combos in air.
⚡ Intelligent Action Masking

GigaLearn evaluates GetActionMask(player, state) on every step to prevent illegal or useless actions from wasting policy entropy:

  • Air Actions Masked on Ground: Disables aerial roll/pitch while car has ground contact.
  • Ground Driving Masked in Air: Disables pure steering/throttle while airborne.
  • Zero Boost Mask: Disables boost actions when player.boost == 0.
  • Flip Mask: Enables jump/dodge actions only when player.HasFlipOrJump() or when turtled on roof.

🧠 PPO Learner Configuration

The training loop is configured via GGL::LearnerConfig and GGL::PPOLearnerConfig.

C++ • Training Setup 
GGL::LearnerConfig cfg = {};
cfg.numGames = 128;              // 128 parallel RocketSim arenas
cfg.tickSkip = 8;                // 8 physics ticks per step (15 Hz decisions)
cfg.actionDelay = 7;             // Action execution lag
cfg.tsPerSave = 1'000'000;       // Save checkpoint every 1M steps
cfg.checkpointsToKeep = 16;

// PPO Hyperparameters
cfg.ppo.tsPerItr = 100'000;      // Steps collected per PPO update iteration
cfg.ppo.miniBatchSize = 25'000;  // Mini-batch size for GPU memory efficiency
cfg.ppo.epochs = 2;              // Optimization epochs per iteration
cfg.ppo.policyLR = 3e-4f;        // Policy learning rate
cfg.ppo.criticLR = 3e-4f;        // Critic learning rate
cfg.ppo.clipRange = 0.2f;        // PPO surrogate loss clipping range
cfg.ppo.gaeGamma = 0.99f;        // Discount factor
cfg.ppo.gaeLambda = 0.95f;       // GAE factor

// Model Architecture (Actor / Critic)
cfg.ppo.policy.layerSizes = { 512, 512, 512 };
cfg.ppo.policy.activationType = GGL::ModelActivationType::RELU;
cfg.ppo.critic.layerSizes = { 512, 512, 512 };

🎯 Adaptive Target-Entropy Controller

💡 SAC-Style Automatic Temperature Tuning for PPO

Standard fixed entropyScale causes entropy to collapse over long runs. GigaLearn includes an automatic target-entropy controller with anti-windup:

  • entropyTarget > 0: Sets a normalized target entropy fraction (e.g. 0.40).
  • entropyAdjustRate: Multiplicative gain per iteration (default 0.15).
  • Anti-Windup Protection: Holds scale at initial value until measured entropy first reaches target before integrating.

⚔️ Self-Play & Skill Tracker

Historical Self-Play
Pits the current training policy against past checkpoint snapshots to prevent catastrophic forgetting and circular meta exploitation.
trainAgainstOldVersions: Enable self-play mixing
trainAgainstOldChance: Probability (e.g. 0.20)
tsPerVersion: Timesteps between snapshot versions
maxOldVersions: Pool size limit (e.g. 32)
Skill Tracker (TrueSkill / Rating)
Simulates background evaluation matches in dedicated arenas to produce an objective bot skill rating graph over time.
numArenas: Evaluation arena count (e.g. 16)
updateInterval: Iterations between rating matches
simTime: Match duration per arena (e.g. 45s)

🤖 Model Inference (RLBot Deployment)

Use GGL::InferUnit to load checkpoints and evaluate actions in real-time matches:

C++ • BotInference.cpp 
#include <GigaLearnCPP/Util/InferUnit.h>
#include <RLGymCPP/ObsBuilders/DefaultObs.h>
#include <RLGymCPP/ActionParsers/DefaultAction.h>

using namespace GGL;

InferUnit* inferUnit = new InferUnit(
    new RLGC::DefaultObs(),
    obsSize,
    new RLGC::DefaultAction(),
    sharedHeadConfig,
    policyConfig,
    "checkpoints/main/latest",
    false // useGPU (false for fast CPU bot runtime)
);

// On match tick packet:
RLGC::Action act = inferUnit->InferAction(
    player,
    gameState,
    true,   // deterministic mode for match play
    1.0f    // temperature
);
